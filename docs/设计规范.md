# EnoughBox 设计规范 —— 深灰极简 · Apple 质感

> 本 App 唯一的 UI 风格。Slogan：**I don't need much.** 视觉语言与 [newking](../../newking/docs/设计规范.md) 对齐：暖白/深灰底、墨黑文字、**无彩色强调**、大圆角 + 发丝阴影。
> 实现侧以 `EnoughBox/Design/DesignTokens.swift` 为唯一令牌来源（对应 newking 的 `index.css`）。

---

## 1. 风格定位

- **底色**：暖白 `#F5F5F7` / 深灰 `#242426`，大量留白。
- **文字**：四级灰阶（`ink` → `ink-faint`），禁止纯 `#000` / `#FFF` 大面积铺底（按钮白字除外）。
- **强调色**：深灰 `#171717`（浅色）/ `#484849`（深色）。**禁止**蓝/紫/绿等彩色作为 UI 强调（状态图标可用 SF Symbol 默认灰阶）。
- **质感**：卡片 + 柔和阴影 + 圆角 11pt（`rounded-2xl` 等价）+ 发丝边框 `black/8%` 或 `white/8%`。
- **氛围**：Apple 系统设置 / Linear / 克制高级。

---

## 2. 设计令牌

### 颜色（RGB 0–255，Swift 用 `Color(red:green:blue:)` 或 Asset Catalog）

| 令牌 | 浅色 | 深色 | 用途 |
|------|------|------|------|
| `page` | `#F5F5F7` | `#242426` | 窗口 / 列表区底色 |
| `shell` | `#FFFFFF` | `#343436` | 主内容区（右栏设置面板） |
| `nav` | `#FFFFFF` | `#1D1D1D` | 顶栏 / 侧栏头部 |
| `card` | `#FFFFFF` | `#2C2C2E` | 卡片、输入框、插件行 |
| `ink` | `#1D1D1F` | `#E0E0E0` | 主文字 |
| `ink-soft` | `#3A3A3C` | `#C6C6C8` | 次级 |
| `ink-muted` | `#6E6E73` | `#A8A8AA` | 说明 |
| `ink-faint` | `#86868B` | `#7A7A7D` | 占位 / eyebrow |
| `accent` | `#171717` | `#484849` | 主按钮、选中条、焦点 |
| `accent-hover` | `#404040` | `#5A5A5B` | 按钮 hover |
| `accent-soft` | `#F5F5F7` | `#262627` | 浅底标签 / 选中背景 |
| `border` | `black 8%` | `white 8%` | 发丝分隔 |

### 阴影

| 令牌 | 浅色 | 深色 |
|------|------|------|
| `shadow-apple` | `0 4 16 / 0.06, 0 1 3 / 0.04` | `0 2 10 / 0.18, 0 1 2 / 0.1` |
| `shadow-apple-lg` | `0 12 32 / 0.1` | `0 6 20 / 0.22, 0 1 4 / 0.14` |
| `shadow-apple-input` | `0 1 2 / 0.04` | `0 2 8 / 0.16, 0 1 2 / 0.1` |

SwiftUI：`shadow(color:radius:x:y:)` 叠两层近似即可；深色模式浮层优先 **阴影 + 微 inset 高光**，少用硬边框。

### 圆角

| 场景 | 值 |
|------|-----|
| 卡片 / 面板 / 插件行 | **11pt** |
| 主按钮 / 胶囊输入 | **999pt**（full） |
| 小图标底 | **10pt** |

### 字体

- 正文：**SF Pro** / **PingFang SC**（`system` + `.design(.default)`）
- 等宽：SF Mono / Menlo（版本号、快捷键显示）
- 字重：标题 `.semibold`，正文 `.regular`，说明 `.regular` + `ink-muted`

### 动效

- 缓动：`cubic-bezier(0.22, 0.61, 0.36, 1)` → SwiftUI `.animation(.timingCurve(0.22, 0.61, 0.36, 1), value:)`
- Hover / 选中：**200ms**
- 按钮按压：`scaleEffect(0.95)` on press
- 尊重 `accessibilityReduceMotion`

## 3. EnoughBox 组件规范

| 组件 | 样式 |
|------|------|
| **主窗口** | `page` 底；最小尺寸 720×480；无多余装饰 |
| **顶栏** | 应用名仅 macOS **窗口标题**（左侧）；工具栏只放插件中心、外观等操作 |
| **左侧栏** | 宽 220pt；`page` 底；插件列表行高 44pt；选中：左侧 3pt `accent` 竖条 + `accent-soft` 底 |
| **右侧设置区** | `shell` + `shadow-apple` 内卡片分区；section 标题 `ink-faint` 小写大写 + 字间距 |
| **空状态** | 居中；slogan 一句 + 标题 + 说明 +「打开插件中心」按钮（不重复应用名） |
| **插件中心** | 模态 sheet；列表卡片；**安装按钮 App Store 式**（胶囊 → 圆环进度 → 安装中旋转环，无数字） |
| **设置行** | 左 label `ink` + 右控件；分隔线 `border`；热键用 KeyboardShortcuts.Recorder 原生样式外包一层 `card` 圆角 |
| **主题切换** | 顶栏图标按钮；样式同 newking `site-theme-toggle`：浅 `card`+边框 / 深 `nav`+白边 8% |
| **Toast** | `card` + `shadow-apple-lg`，圆角 11pt，2s 自动消失 |

## 4. 主题切换

- 三种模式：**跟随系统** / **浅色** / **深色**（默认跟随系统）。
- 存储：`UserDefaults` key `appearance`（`system` | `light` | `dark`）。
- SwiftUI：`preferredColorScheme` + 自定义 `Theme` Environment；**禁止**视图内硬编码 `#F5F5F7` 等，一律走 `DesignTokens`。
- 深色 `page` 可选极弱 radial 高光（对齐 newking `.dark body` 5% 椭圆渐变）。

---

## 5. 硬性规则

1. **无彩色强调**：主交互只用 `accent` 灰阶。
2. **令牌唯一来源**：新增色值先改 `DesignTokens.swift` 再改本文档。
3. **阴影圆角统一**：卡片系 `shadow-apple` + 11pt 圆角。
4. **文案**：只用 String Catalog key；对照表见 `docs/MVP.md` §10；增删改先更新表与 `.xcstrings`。
5. **插件 UI**：插件设置视图使用 SDK 的 `PluginSettingsContainer`；插件 bundle 内自带 `Localizable.xcstrings`。

---

## 6. 国际化

- 宿主：`EnoughBox/Resources/Localizable.xcstrings`（en + zh-Hans）
- 插件：各自 bundle 内 `.xcstrings`；协议用 `localizedName(for:)`
- 插件中心：`manifest.json` 的 `nameLocalized` / `descriptionLocalized`
- 细节见 [`docs/MVP.md` §11](MVP.md#11-国际化i18n)
