# 插件文档

这里记录每个插件的功能边界、依赖、安装方式、调试方法和常见故障。

## 文档约定

- 每个插件一份文档，文件名使用插件 ID 或稳定的插件名称。
- 记录「源码在哪里」「运行时从哪里加载」「需要哪些权限」「如何验证」。
- 遇到故障时先判断属于哪一层：源码、Xcode 工程/缓存、Application Support 已安装副本，还是 macOS 权限。
- 修改插件协议或 SDK 后，必须同时检查宿主和已安装 `.plugin` 是否来自同一次构建。
- 文档里的菜单名称要以当前 Xcode 版本实际显示为准，不把不存在的按钮写成操作步骤。
