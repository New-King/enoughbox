# `com.enoughbox.clipboard` 内置剪贴板工具

## 基本信息

- 源码：`EnoughBox/Features/Clipboard/`
- 快捷键：`com.enoughbox.clipboard.panel`
- 权限：读取系统剪贴板；自动粘贴需要辅助功能
- 历史存储：`~/Library/Application Support/EnoughBox/clipboard/`

快捷键呼出浮窗，支持搜索、分类（最近 / 全部 / 文本 / 图片 / 其他）、列表选用、复制与删除。默认点击条目或回车会粘贴到打开浮窗前的应用并关闭浮窗；钉住后，点击与回车只粘贴、不关窗。钉住状态会记住。行内复制图标只写入系统剪贴板，并在屏幕中央提示「已复制到剪贴板」。再次按快捷键或 `Esc` / `⌘W` / `⌘Q` / 关闭按钮可关掉浮窗。自动粘贴需要辅助功能权限。

浮窗跟随宿主外观设置，与翻译浮窗相同：打开时读取当前主题，关掉再开才会更新。使用 `DesignTokens` 与 `appleShadow`；关闭时清空搜索状态并释放缩略图缓存。大文本（>4KB）与图片落盘，列表只加载可见缩略图。底部左对齐快捷键提示：回车粘贴、上下选择、左右分类、`/` 搜索，项之间用浅色竖线分隔。搜索框占位仅「搜索」。

默认保留最近 50 条历史。「最近」按最新复制和浮窗内操作混排，最多 20 条；「全部」按复制时间排序，最新在前。

## 验证

1. 工具中心启用「剪贴板」，设置页录制快捷键。
2. `Cmd+B` / `Cmd+R`。
3. 复制几段文本与一张图片，按快捷键打开浮窗。
4. 切换分类与搜索；未钉住时点击条目应粘贴到原应用并关闭浮窗。
5. 点左上角图钉后，再点击或回车应粘贴且窗口不关；再点图钉取消。行内复制只写入剪贴板并在屏幕中央提示「已复制到剪贴板」。删除条目后不再出现。`Esc` / 快捷键仍可关闭。
6. 工具「移除」后热键失效、监听停止。
