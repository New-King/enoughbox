# EnoughBox 架构

## 总览

```
┌─────────────────────────────────────────────────────────────┐
│  EnoughBox.app（宿主 Host）                                    │
│  ├─ UI：侧栏 + 设置区 + 插件中心                              │
│  ├─ PluginLoader：扫描 / 加载 / 生命周期                      │
│  ├─ HotkeyCenter：全局热键（KeyboardShortcuts）               │
│  ├─ HostServices：OCR / 选区 / 剪贴板 / 浮窗（供插件调用）     │
│  └─ PluginStore：manifest 拉取、安装、校验                    │
└─────────────────────────────────────────────────────────────┘
         │ 依赖 EnoughBoxPluginSDK（Swift Package）
         ▼
┌──────────────────┐  ┌──────────────────┐
│ Translate.plugin │  │ Screenshot.plugin │  …
└──────────────────┘  └──────────────────┘
```

**原则**：宿主零业务；所有业务能力在插件内。宿主只提供运行时、权限、系统 API 封装、UI 壳。

## 插件模型

### 包格式

```
MyTool.plugin/          # macOS Bundle
├── Contents/
│   ├── Info.plist      # NSPrincipalClass = MyToolPlugin
│   └── MacOS/MyTool
```

### 协议（EnoughBoxPluginSDK）

```swift
@objc public protocol EnoughBoxPlugin: AnyObject {
    var id: String { get }
    /// 侧栏显示名（从插件 bundle 的 Localizable 读取，见 docs/MVP.md §11）
    func localizedName(for locale: Locale) -> String
    var iconName: String { get }      // SF Symbol
    var version: String { get }

    func activate(host: HostServices)
    func deactivate()
    func makeSettingsView() -> NSViewController  // 或 SwiftUI via NSHostingController
}
```

- 协议必须 `@objc`，`principalClass` 动态加载（参考 [MioIsland 插件模板](https://github.com/MioMioOS/mio-plugin-template)）。
- SDK 以 **dynamic library** 形式链接，保证宿主与插件共享同一协议类型 identity。

### 生命周期

```
安装 → 拷贝至 ~/Library/Application Support/EnoughBox/Plugins/
     → 校验 SHA256 + 签名（官方包）
     → 检查 minMacOS / architectures / minHostVersion
     → 写入本地 registry（已安装列表）
启用 → 按 capabilities 引导权限 → Bundle.load → activate
禁用 → deactivate → 注销热键
卸载 → deactivate → 删除 bundle → 更新 registry
```

## HostServices（宿主暴露给插件）

MVP 先定义接口，Phase 2 逐步实现：

| 服务 | 系统 API | MVP |
|------|----------|-----|
| `hotkeys` | KeyboardShortcuts | ✅ 注册/注销 |
| `clipboard` | NSPasteboard | ✅ 划词为空时给翻译插件用剪贴板文本 |
| `settings` | Defaults | ✅ 插件命名空间存储 |
| `credentials` | KeychainAccess | ✅ API Key |
| `selection` | Accessibility | ✅ 划词：先 AXSelectedText，部分 App 再短暂 Command-C（还原剪贴板）。不弹系统 TCC 框；以系统设置开关为准 |
| `ocr` | Vision | ⏳ Phase 2 |
| `capture` | ScreenCaptureKit | ⏳ Phase 2 |
| `floatingPanel` | NSPanel | ⏳ Phase 2 |

## 插件中心

MVP 使用 **静态 manifest**（托管 GitHub Raw / Releases）。**官方 registry 为 curated 审核制**，见 [插件发布.md](插件发布.md)。

```json
{
  "version": 1,
  "hostMinVersion": "0.1.0",
  "plugins": [
    {
      "id": "com.enoughbox.sample",
      "name": "Sample",
      "nameLocalized": { "en": "Sample", "zh-Hans": "示例" },
      "description": "Verify install, settings, and shortcuts",
      "descriptionLocalized": {
        "en": "Verify install, settings, and shortcuts",
        "zh-Hans": "验证插件安装、设置与快捷键"
      },
      "version": "0.1.0",
      "icon": "puzzlepiece.extension",
      "downloadUrl": "https://…/Sample.plugin.zip",
      "sha256": "…",
      "minHostVersion": "0.1.0",
      "minMacOS": "14.0",
      "architectures": ["arm64", "x86_64"],
      "capabilities": ["hotkey", "clipboard"],
      "repositoryUrl": "https://github.com/…/enoughbox",
      "author": "enoughbox"
    }
  ]
}
```

**运行时只认 Application Support**，宿主 Release 包 **不内嵌** 业务 `.plugin`。安装源可有两条，接口相同、加载路径相同：

| 源 | 何时用 | 行为 |
|----|--------|------|
| `LocalBuildSource` | **Debug / Xcode 联调** | 从 `BUILT_PRODUCTS_DIR`（App 旁的 `<id>.plugin`）拷到 Application Support。`Cmd+B` 编宿主会顺带编插件 target，点「安装」即覆盖本地已装副本。 |
| `RemoteDownloadSource` | **Release / 用户** | `URLSession` 按 manifest `downloadUrl` 拉 zip → SHA256 → 解压 → 写入同一 Plugins 目录。当前可先占位，有 CI 产物后再接。 |

安装器按顺序尝试：Debug 先本地构建产物，没有再走远程；Release 只走远程。卸载只删 Application Support，不碰 App 包。

正式安装流程：`URLSession` 下载 → SHA256 → 解压（Archive.framework）→ 签名校验 → 兼容性检查 → 移入 Plugins 目录。

**官方中心不提供用户上传**；第三方 sideload 为 Phase 3 可选，默认关闭（见 [插件发布.md §8](插件发布.md#8-sideload高级默认关闭)）。

## 插件发布与审核（开源后）

| 项 | 决策 |
|----|------|
| 官方列表 | **PR + 人工审核 + CI 构建** |
| 二进制来源 | 仅 CI / 维护者签名后的 `downloadUrl` |
| 权限 | manifest `capabilities` 声明，安装/启用前告知 |
| 兼容性 | `minMacOS`、`architectures`、`minHostVersion` |
| 随意上传 | **不支持** |

## 安全

- 仅加载 `Application Support/EnoughBox/Plugins` 下已安装 bundle。
- 官方插件：SHA256 匹配 manifest + **维护者 Team ID 签名**；Debug 可 `--skip-plugin-verify`。
- 安装前校验 `minMacOS`、`architectures`、`minHostVersion`；不满足则拒绝并提示。
- `capabilities` 与运行时行为不一致的插件不应通过审核；后期宿主可拒绝未声明敏感能力。
- 插件 API Key 只进 Keychain，不进 UserDefaults。
- 默认 **禁止** 非官方 sideload；Phase 3 高级开关见 [插件发布.md](插件发布.md)。
