# EnoughBox 架构

## 总览

```
┌─────────────────────────────────────────────────────────────┐
│  EnoughBox.app（宿主 Host）                                    │
│  ├─ UI：侧栏 + 设置区 + 内置工具中心                          │
│  ├─ BuiltInToolCatalog：内置工具清单                          │
│  ├─ HotkeyCenter：全局热键（KeyboardShortcuts）               │
│  ├─ HostServices：系统 API 封装                                │
│  └─ BuiltInTools：翻译等随 App 发布的工具                     │
└─────────────────────────────────────────────────────────────┘
```

**原则**：工具直接编进 EnoughBox.app；用户只管理启用状态。

## 内置工具模型

内置工具随宿主一起编译。工具中心的“启用”和“移除”只更新本地启用列表：

```
EnoughBox.app 编译时包含工具代码
        ↓
工具中心读取 BuiltInToolCatalog
        ↓
启用 → 写入 registry → 加入侧栏并启动工具
移除 → 从侧栏移除并停止工具
```

当前翻译工具源码位于 `EnoughBox/Features/Translate/`。

## 内置工具中心

工具中心使用本地静态目录，不拉取远程 manifest：

- “启用”把工具 ID 写入 Application Support 的 registry。
- “移除”从 registry 删除工具 ID，并停止工具。
- 代码和资源始终随宿主发布。

## 第三方依赖（SPM）

| 包 | 用途 |
|----|------|
| [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) | 热键 + 录制 UI |
| [Defaults](https://github.com/sindresorhus/Defaults) | 类型安全配置 |
| [KeychainAccess](https://github.com/kishikawakatsumi/KeychainAccess) | 密钥 |
| [LaunchAtLogin](https://github.com/sindresorhus/LaunchAtLogin) | 可选，Phase 1.1 |
| [Sparkle](https://sparkle-project.org/) | 可选，宿主自动更新 |

**不引入** Electron / Tauri / Rubick 运行时。

---

## 运行时数据

- 只在 `Application Support/EnoughBox/registry.json` 保存用户启用的工具 ID 和设置。
- 工具代码与资源随 `EnoughBox.app` 发布，不从网络下载可执行代码。
- 辅助功能权限仍由 macOS TCC 管理；工具只负责发起授权提示并打开系统设置。
