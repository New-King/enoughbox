# EnoughBox 开发前必读

## 项目定位

EnoughBox 是一个 macOS 内置工具箱。

- 工具代码直接编译进 `EnoughBox.app`
- 用户通过工具中心启用或移除工具
- 工具状态保存在 Application Support 的 registry
- 当前主要工具是内置翻译工具

## 目录约定

- 宿主入口：`EnoughBox/`
- 内置工具：`EnoughBox/Features/`
- 翻译工具：`EnoughBox/Features/Translate/`
- 选区读取：`EnoughBox/Services/HostServices/SelectionCapture.swift`
- 全局快捷键：`EnoughBox/Services/HotkeyCenter/`
- 工具状态：`EnoughBox/Services/Tools/`
- 工程配置：`project.yml`
- 生成工程：`EnoughBox.xcodeproj/`

## 修改前必须遵守

1. 先阅读本文件、`AGENTS.md`、`docs/架构.md` 和对应工具文档。
2. 先执行 `git status`，确认当前工作区状态。
3. 先判断问题属于编译、运行、权限、界面还是业务逻辑。
4. 一次只改一个问题，不要同时重构多个模块。
5. 不要修改已经正常工作的选区读取、权限流程和工程依赖。
6. 不要为了修一个 Swift 错误而删除缓存、重置用户数据或改工程输出目录。

## 翻译 API 开发规则

- 真实服务通过独立的 `Translator` 实现接入
- API Key 与普通设置一样保存在 UserDefaults
- 不把 API Key 写入日志或源代码
- 网络请求必须异步，不能阻塞主线程
- 处理空输入、超时、取消、网络失败和服务端错误
- 不要修改选区捕获流程来适配 API
- 请求成功后只更新翻译结果，不改变原文和剪贴板
- 用户切换语言或重复点击翻译时，取消或忽略旧请求

推荐调用关系：

```text
TranslationPanel
    → Translator
        → YoudaoTranslator / DeepSeekTranslator / 系统翻译（macOS 15+）
```

## 修改后必须验证

1. 使用完整 Xcode 执行 `Cmd+B`，确认 Build Succeeded。
2. 使用 `Cmd+R` 启动 EnoughBox。
3. 确认工具中心、启用/移除、工具设置页正常。
4. 确认快捷键仍然可用。
5. 确认翻译浮窗的手动输入仍然可用。
6. 确认外部 App 选区翻译仍然可用。
7. 确认剪贴板内容没有被永久替换。
8. 检查 `git diff`，确认没有无关改动。

如果 Build 失败，先修复编译错误再继续；不要假设没有改到的文件一定没问题。
